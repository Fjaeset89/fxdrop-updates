# FX Drop updates

**New user? Download FX Drop here:** [FX-Drop-Setup.zip](https://github.com/Fjaeset89/fxdrop-updates/raw/main/FX-Drop-Setup.zip)
— unzip it and double-click `Install FX Drop.cmd`. After that FX Drop keeps itself up to date.

Installed copies read `v2/latest.json` every few hours and install newer versions on their own.
Each update is signed, and FX Drop refuses anything that isn't. Don't edit these files by hand.
(`latest.json` in the root is kept at 1.1.0 on purpose: versions before 1.2.1 can't restart after
updating, so they're left alone.)
